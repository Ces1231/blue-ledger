Glide Build
Quiz Screens in Glide
Screen 1 — Quiz selection list
~45 min
1
Add Screen → List → source: 📝 Quiz Bank
Filter to show unique categories only (History and Constitution). Each row shows: Quiz name, category badge, XP available, difficulty distribution. Tap → Quiz Taking screen.
2
Add 'Attempts remaining' computed column
In Data Editor → 📝 Quiz Sessions → Add Column → Rollup → Count rows where Member # = current user AND Category = this quiz AND Date is in current semester. Display 'X/3 attempts used' on the list item.
3
Hide quiz when attempts exhausted
Quiz item → Visibility condition: IF 'Attempts This Semester' < 3 → show. ELSE → show a 'No attempts remaining' locked state. Don't remove the row — show it grayed out so brothers know it exists.
4
Add to nav bar
Add Quizzes as a sub-section within the existing Quests & Badges tab. Or add as its own nav tab with a book icon. Visible to all roles.
Screen 2 — Quiz taking
~60 min
1
Create a Form screen with 5 Choice components
New Screen → Form → source: 📝 Quiz Attempts. Add 5 Choice fields, each mapping to a question from the selected quiz. Use 'Single select' type — only one answer per question. Label each field with the question text.
2
Pre-fill question text using Lookup columns
In Data Editor → Add Lookup columns that pull Question 1–5 text and Options A–D from the 📝 Quiz Bank based on the selected quiz category and a randomized or sequential question index.
3
Configure Submit action
Submit → Action chain: (1) Add Row to 📝 Quiz Sessions with all 5 answers. (2) Set Session ID = ROW template. (3) Call Make.com webhook with Member #, Quiz Category, and all 5 answers. (4) Show notification 'Quiz submitted — results incoming!' (5) Navigate to Quests & Badges screen.
4
Add a retake countdown
Below the start button on the quiz intro screen, show: 'Attempts this semester: X/3'. Disable the Start Quiz button if attempts = 3. Add a 'retakes reset each semester' note.
Make.com
Quiz Scoring Scenario
Scenario: Quiz submitted → score → XP → badge
~30 min to build
T
Trigger: Webhook (called from Glide submit action)
Receives: Member #, Member Name, Quiz Category, Answer 1–5. Immediately available as variables in the scenario.
1
Look up correct answers from Quiz Bank
Google Sheets → Search Rows → 📝 Quiz Bank where Category = received category. Pull the 5 correct answers into variables.
2
Score the answers (Router)
Compare each of the 5 submitted answers against the correct answers. Count matches. Calculate score: (correct / 5) × 100.
3
Determine Pass/Fail
IF score ≥ 80 → Pass. ELSE → Fail. Route to two branches.
4
Pass branch: Award XP
Calculate XP: sum the XP Award value for each correct question answered. Add Row to 📋 Engagement Log: Activity = 'Quiz Pass ({category})', XP = calculated amount, Member #, date.
5
Pass branch: Update Total XP
Google Sheets → Update Row in 👥 Users where Member # matches. Total XP = current Total XP + calculated quiz XP.
6
Perfect score check
IF score = 100 AND 'Scholar' NOT in Earned Badges → append 'Scholar' to Earned Badges field. Also add a 150 XP bonus row to Engagement Log: Activity = 'Perfect Quiz Score'.
7
Update Quiz Sessions row
Update the 📝 Quiz Sessions row with the final Score %, Pass/Fail, XP Awarded, and Badge Triggered. This is what Glide reads to show 'Attempts this semester'.
💡
The retake limit is enforced in Glide (via computed column) — not in Make.com. Make.com scores every submission it receives. Glide prevents the 4th submission from ever reaching Make.com by hiding the Start Quiz button.
