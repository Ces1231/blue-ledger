Step 1
Upload Avatars to Cloudinary
Cloudinary setup — one-time, 10 minutes
Free tier
1
Create free account
Go to cloudinary.com → Sign Up (free). No credit card needed for the free tier (25GB storage, more than enough for 5 PNGs).
2
Upload all 5 PNGs
Dashboard → Media Library → Upload → select all 5 files from assets/avatars/. Cloudinary assigns each a permanent public URL automatically.
3
Copy each direct URL
Click each uploaded image → copy the 'Secure URL' (starts with https://res.cloudinary.com/...). You need all 5 URLs for the next step. Save them in a notes file temporarily.
4
Alternative: Use Glide's built-in storage
If you prefer not to use Cloudinary: in Glide Data Editor → 👥 Users → click any row's avatar cell → upload the PNG directly. Glide hosts it automatically. The URL is auto-filled. Repeat for each avatar level using a template row, then the If-Then-Else formula points to those Glide-hosted URLs.
Step 2
Glide Computed Columns
Add two If-Then-Else columns to the Users table.
Column 1: Avatar Image URL
Data Editor → If-Then-Else
1
Add Column → If-Then-Else → name: Avatar Image URL
Data Editor → 👥 Users → + Add Column → If-Then-Else.
2
Build the 5-tier formula
IF Total XP ≥ 2500 → paste Chapter Icon URL
ELSE IF Total XP ≥ 1500 → paste Gold Legend URL
ELSE IF Total XP ≥ 1000 → paste Silver Elite URL
ELSE IF Total XP ≥ 500 → paste Bronze Varsity URL
ELSE → paste Base (Neophyte) URL
3
Test immediately
In the Data Editor, manually change a test member's Total XP to 600. The Avatar Image URL column should instantly show the Bronze URL. Change to 1200 — should show Silver URL. Verify all 5 thresholds.
Column 2: Avatar Level Label (if not already set)
Data Editor → If-Then-Else
1
Check if Avatar Level column already exists
If you built this in Week 2–3, it already exists. Skip this step. If not, add it now.
2
Formula
IF Total XP ≥ 2500 → 'Chapter Icon'
ELSE IF Total XP ≥ 1500 → 'Gold Legend'
ELSE IF Total XP ≥ 1000 → 'Silver Elite'
ELSE IF Total XP ≥ 500 → 'Bronze Varsity'
ELSE → 'Neophyte'
Step 3
Wire Avatars to Screens
Place the Avatar Image URL column on 4 screens.
4 places the avatar appears
~30 min total
1
Home Dashboard — hero image
Home screen → find the avatar placeholder (or add an Image component at the top). Source: Avatar Image URL column. Size: Large (fills the card width). This is the most prominent placement — first thing a brother sees on open.
2
Digital ID Card
Digital ID screen → replace the initials circle with an Image component. Source: Avatar Image URL. Size: Medium (100px). Place above the member name.
3
Leaderboard list rows
Leaderboard → list item configuration → Left image: Avatar Image URL (small, circular crop). This replaces the plain initials circle with the actual avatar PNG — the leaderboard instantly becomes more visual.
4
Chapter Directory
Directory → list item → Left image: Avatar Image URL. Same as leaderboard — each member row shows their level avatar, making high-XP brothers immediately recognizable at a glance.
⚠️
Make sure the Image components are set to 'Circle' crop on the Leaderboard and Directory — rectangular PNGs cropped to circles look clean. On the Home Dashboard and Digital ID, use 'Square with rounded corners' for the full portrait effect.
Unlock Moment
Making the Unlock Feel Like a Reward
The level-up itself should feel earned, not silent.
Creating a satisfying level-up experience in Glide
No code required
1
Add a 'Level Up!' notification via Make.com
In your XP update scenario (Week 4), add a check after updating Total XP: IF new XP crosses a threshold (500, 1000, 1500, 2500) → trigger a Glide notification (via webhook or direct app notification if available) saying 'Level Up! You're now a [Level Name].' This fires the moment a scan or quiz pushes them over a threshold.
2
Add a level progress bar to the Home Dashboard
Below the XP number, add a progress bar component. Value = (Total XP - previous threshold) / (next threshold - previous threshold) × 100. Label: '340 XP to Gold Legend'. This creates constant visible momentum.
3
Post the leaderboard screenshot in the chapter group chat after each event
After every chapter meeting scan, screenshot the Leaderboard — it now shows real avatars for high-tier members. Post in the group chat. Social proof drives app opens more than any in-app notification.
