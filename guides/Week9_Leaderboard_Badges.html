Leaderboard Enhancements
Upgrade the Leaderboard screen
~45 min
1
Add rank number column
Data Editor → 👥 Users → Add Column → Row Number. This auto-assigns a sequential number. Then add another If-Then-Else column Rank that orders by XP descending. Glide doesn't have native rank-by-value, so the simplest approach: sort the list by Total XP descending — the visual order becomes the rank, no extra column needed.
2
Add semester filter
Above the leaderboard list, add a Choice component (Semester filter: 'All Time' / 'Fall 2025' / 'Spring 2026'). When filter changes, show XP earned only within that period by adding a Rollup column per member summing XP from Engagement Log within the date range. Semester filter drives competitive short-term engagement.
3
Highlight the current user's row
Each list row → Conditional Style → IF Member # = Current User's Member # → apply gold background color. This makes brothers immediately spot themselves when they open the leaderboard.
4
Add 'Top 3' callout at the top
Above the list, add 3 Text components showing Rank 1/2/3 member names and XP using Lookup columns (find the member with highest XP, second-highest, third-highest via Relations or manual Lookup). This is the podium section that makes the leaderboard feel alive.
5
Chapter stats summary
Add a small stats card below the leaderboard: Total Active Members, Total Chapter XP (Rollup sum of all members' XP), Total Service Hours (Rollup sum). This makes the leaderboard feel like a chapter achievement dashboard, not just a competition.

Achievement Gallery & Badge System
Quests & Badges screen — full configuration
~60 min
1
Build the badge list from 🎖️ Quests & Badges tab
Quests & Badges screen → List layout → source: 🎖️ Quests & Badges tab. Each row shows: Badge icon (URL), Badge Name, Category, Requirement text, XP Bonus, Rarity badge, Earned/Locked indicator.
2
Add Earned? computed column
Data Editor → 🎖️ Quests & Badges → Add Column → If-Then-Else → name: Earned By Current User?. Formula: IF Badge Name is contained in [Current User's Earned Badges field] → 'Yes' ELSE → 'No'. This is the core earned/locked logic.
3
Style earned vs locked badges differently
Badge list item → Conditional Styling → IF Earned By Current User? = 'Yes' → green background, full opacity. IF 'No' → gray background, 50% opacity (use a style that dims it). Earned badges visually pop; locked ones fade back. Add a lock icon to locked badges using a conditional Image component.
4
Sort: earned first
Sort the badge list: Earned By Current User? = 'Yes' appears first, then locked badges. Within earned, sort by most recently earned (if you track earn date). This means a brother's gallery fills from the top as they earn more.
5
Badge detail screen on tap
Tap any badge → Detail screen showing: large icon, badge name, full requirement description, XP bonus, rarity, earned date (if earned), 'Not yet earned — here's how' if locked. This is where brothers go to understand exactly what they need to do next.

Make.com — badge threshold scenario (covers 5 badges)
Add to existing XP update scenario
T
Add after every XP update (existing scenarios)
At the end of your Engagement Log → XP Update scenario, add a Router module that runs badge checks for every member whose XP just changed.
1
Service hours badges (25hr + Centurion)
After each verified service log entry: Rollup total service hours for the member. IF total ≥ 25 AND '25-Hour Builder' NOT in Earned Badges → award badge + 250 XP bonus. IF total ≥ 100 AND 'The Centurion' NOT in Earned Badges → award badge + 1000 XP bonus.
2
Punctual badge (10 on-time meetings)
After each Chapter Meeting (on time) check-in: Count rows in Engagement Log for this member where Activity = 'Chapter Meeting (on time)'. IF count = 10 AND 'Punctual' NOT in Earned Badges → award badge + 200 XP bonus.
3
Faithful badge (3 consecutive semesters on time)
After Dues Paid: Check last 3 semester entries for this member. IF all 3 = 'Paid' with dates before deadline AND 'Faithful' NOT in Earned Badges → award badge + 300 XP bonus. This requires tracking semester deadlines in a config tab.
4
Chapter Legend badge (XP ≥ 2500)
After every XP update: IF Total XP ≥ 2500 AND 'Chapter Legend' NOT in Earned Badges → award badge + 500 XP bonus. Update Avatar Level to 'Chapter Icon'. This cascades to update the avatar image URL on the next sync.
5
Road Warrior badge (conference attendance)
After any Engagement Log row where Activity = 'Regional/National Conference': IF 'Road Warrior' NOT in Earned Badges → award badge + 300 XP bonus. This fires once, the first time a conference activity is logged for a member.
