PIA Builder Screen
PIA Builder screen — full configuration
~60 min
1
Screen setup
Add Screen → Details → source: 📊 PIA Builder tab. Visibility: Role = Admin OR Role = PIA. Name: 'PIA Builder'. Nav tab with chart icon. Add to Operations section in sidebar.
2
Summary stat cards at top
Add 3 stat display components using Rollup columns: (1) Program Count = count of rows in PIA Builder tab. (2) Total Brothers Engaged = sum of '# Brothers Participated'. (3) Total Hours = sum of 'Total Hours Logged'. Display as a 3-column grid at the top of the screen.
3
Program list
Below stats: Inline List → 📊 PIA Builder tab → all rows → sorted by Date descending. Each row shows: Program Area (bold), Program Name, date, brothers count, hours. Tap → Detail view with all fields including Community Partners and Estimated Impact.
4
Add New Program button
Floating button or top-bar button → Add New Program → Form screen → source: 📊 PIA Builder. Fields: Program Area (dropdown: Economic Empowerment / Educational Development / Health & Wellness / Social Action / Chapter Development), Program Name, Date(s), # Brothers Participated, Total Hours Logged, Community Partners, Estimated Impact, Documentation Link. Visible only to Admin and PIA roles.
5
Export PIA button
Top-right button → label: 'Export PDF →' → Action: Open URL → your Make.com webhook URL (generated in next step). The webhook fires the PDF generation scenario. Show a confirmation notification: 'PIA report sent to district email.'
6
Reporting period selector
Above the program list, add a Choice component: Reporting Period (Fall 2025 / Spring 2026 / Full Year 2025). When changed, filter the list to show only programs within that period. This also passes the period as a parameter to the export webhook.
Make.com
PIA Export Automation
Scenario: PIA Export → PDF → Gmail
~45 min to build
T
Trigger: Webhooks → Custom Webhook
Create a new webhook in Make.com. Copy the URL — paste it into the Glide 'Export PIA' button action. The webhook receives: reporting period (from Glide), triggered by (member name and role).
1
Google Sheets → Get Range
Read the entire 📊 PIA Builder tab. Filter rows matching the reporting period received from the webhook. This becomes your report data.
2
Google Docs → Create Document from Template
Create a Google Doc template with placeholders: {{chapter_name}}, {{period}}, {{total_programs}}, {{total_brothers}}, {{total_hours}}, and a table for program rows. Make.com fills in the placeholders with the sheet data. Use 'Create Document from Template' module.
3
Google Drive → Export as PDF
Convert the filled Google Doc to PDF format. Make.com's Google Drive module has an 'Export File' action that converts Docs to PDF. Store the PDF in a designated Drive folder.
4
Gmail → Send Email with Attachment
To: your district or regional contact email. Subject: 'PIA Report — Tau Tau Sigma Chapter — {{period}}'. Body: chapter name, total stats summary, note that the full report is attached. Attachment: the generated PDF from step 3. Add CC to President and PIA Analyst.
5
Update a 'Last Export' timestamp
Google Sheets → Update a cell in the PIA Builder tab (e.g. cell A1 label area) with the timestamp of the last export. Display this on the PIA Builder screen so the Analyst knows when the report was last sent.
💡
Build the Google Doc template first before wiring the Make.com scenario. Create a blank Doc, format it the way your district report should look, add {{placeholders}} for all variable fields, then share it with your Make.com Google account. The template is reusable — you just update the data for each export.

Add analytics to the Admin Panel

Weekly XP trend
Add a bar-chart style visualization using Glide's chart components (if available on your plan) or a Rich Text component with a manually calculated summary. Show XP earned per week for the current semester.

Attendance rate

Dues collection rate
