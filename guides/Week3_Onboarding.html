Glide configuration — profile setup
New Screen → Form
1
Create 3 separate Form screens
Add Screen → Form → data source: 👥 Users. Name them Profile Step 1, Profile Step 2, Profile Step 3. Each form submits to the same row (current user).
2
Lock read-only fields
Member # and Induction Year: add as Text display components, not form fields. Set visibility to read-only. Members must never edit these.
3
Add the progress bar
Use a Progress Bar component at the top of each form. Set value to: Step 1 = 33, Step 2 = 66, Step 3 = 100. Max = 100.
4
Show profile setup only once
Wrap all 3 form screens in a condition: Profile Complete? = No. Once the member completes Step 3, they never see it again (unless they clear a field).
5
Configure Step 3 submit action
Step 3 submit button → Action: Set Column Values (update current row) → then navigate to Digital ID Reveal screen. Make.com fires automatically when Profile Complete? changes to "Yes".

Full Glide Build Order for Week 3
Build these screens in exact order
~3–4 hours total
1
Configure Sign-In (30 min)
Settings → Sign In → Email PIN → paste allowlist → set colors and branding. Test with your own email first.
2
Build Profile Step 1 form (30 min)
New Screen → Form → 👥 Users. Add: Full Name (text, required), Phone (phone), Member # (read-only text), Induction Year (read-only text), Photo (image upload). Add progress bar at 33%.
3
Build Profile Step 2 form (20 min)
Clone Step 1 screen. Replace fields: Employer (text, required), Job Title (text, required), City/State (text, required). Progress bar at 66%.
4
Build Profile Step 3 form (20 min)
Clone Step 2. Fields: LinkedIn URL, Instagram Handle, Twitter Handle (all optional). Progress bar at 100%. Submit button action: navigate to Digital ID screen.
5
Add QR Data column to Users table (10 min)
Data Editor → 👥 Users → Add Column → Template → name: QR Data → template: MEMBER:{Member #}
6
Build Digital ID screen (30 min)
New Screen → Details → 👥 Users. Add: shield image/rich text header, QR Code component (source: QR Data), Full Name title, Member # text, Avatar Level badge, XP total, Status. Add as Tab 2 in nav.
7
Build Home Dashboard (45 min)
New Screen → Details → 👥 Users (current user). Add: greeting text, Avatar Image URL (large image), XP number, Avatar Level pill, 4 action button cards linking to other screens. Set as Tab 1 (default landing).
8
Configure nav bar (15 min)
Layout → Navigation → Tab bar → 5 tabs: Home (house icon), ID Card (card icon), Leaderboard (trophy icon), Quests (star icon), Profile (person icon). Drag to reorder.
9
Set first-time flow logic (20 min)
Home screen → On Load action: IF Profile Complete? = No → Navigate to Profile Step 1. This forces new members through onboarding before they can access the home screen.
10
Test with a second account (15 min)
Add a second test email to the Users tab and allowlist. Sign in on a second device or browser. Walk through the full onboarding flow end-to-end and verify XP fires correctly.
Make.com
Onboarding Automation — Profile Complete → XP
💡 One Make.com scenario handles the entire profile completion reward. Set it up once and it fires automatically for every new member who finishes onboarding.
Make.com Scenario — Profile Completion XP
~20 min to build
T
Trigger: Google Sheets — Watch Rows
Watch 👥 Users tab. Filter: Profile Complete? = Yes AND XP for Profile NOT already logged. Run on: any row update.
1
Action: Add row to Engagement Log
Sheet: 📋 Engagement Log. Values: Log ID (auto), Date (today), Member # (from trigger row), Member Name (from trigger), Activity Type: Complete 100% Profile, XP Awarded: 100, Logged By: System.
2
Action: Update Users row — add XP
Sheet: 👥 Users. Find row where Member # matches. Set Total XP = current Total XP + 100.
3
Action: Append "Architect" badge
Update the same Users row. Set Earned Badges = current value + , Architect. (String append — Make has a text concatenation module.)
4
Action: Mark "Profile XP Awarded" flag
Add a Profile XP Awarded? column to Users tab. Set to "Yes" after this fires. This prevents the scenario from running twice for the same member.
