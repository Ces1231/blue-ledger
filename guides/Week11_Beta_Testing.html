Protocol
Beta Test Protocol
Run this at a real chapter event — not a dry run in someone's living room.
Before the event — setup checklist
48 hours prior
1
Add all E-Board + Chair emails to the allowlist
Every beta tester must be in the Glide allowlist AND have a row in the Users tab with their correct role assigned. Test sign-in before the event — don't troubleshoot in the parking lot.
2
Seed all beta tester profiles
Pre-populate Name, Email, Member #, Induction Year, Role for all beta testers. They'll fill in professional info themselves — but they need the seed data to sign in successfully.
3
Set up a 'Beta Test' event in PIA Builder
Add a row to 📊 PIA Builder for the event you're using as the beta test. This gives the PIA Analyst real data to work with during testing.
4
Prepare a feedback form
Create a simple Google Form: 5 questions. (1) What role did you sign in as? (2) Did sign-in work? (3) What was the most confusing part? (4) What feature impressed you most? (5) What would you change? Share the link in the group chat after the meeting.
During the event — structured test sequence
~90 minutes
1
Minute 0–20: Everyone signs in and completes profile
All beta testers sign in for the first time. Complete the 3-step profile setup. Verify Digital ID shows up with QR code. Note: first sign-in takes 2–3 min per person — run this before the meeting officially starts.
2
Minute 20–45: Live scan by all Chairs
Each Committee Chair opens Scanner and practices scanning at least 3 members. Confirm check-ins write to the sheet. Switch between activity types (Meeting vs Service) mid-session.
3
Minute 45–60: Leaderboard goes live
After scanning, project or share the Leaderboard. Ranks have shifted. Brothers check their position. This is the social validation moment — does it spark conversation? That's the real test.
4
Minute 60–75: Admin and PIA tasks
President: change one member's role in the Admin Panel, award manual XP. Treasurer: mark one member's dues as paid — verify +50 XP fires. PIA Analyst: export the PIA PDF — verify it arrives in the district email.
5
Minute 75–90: Quiz testing
2–3 brothers take the Fraternity History quiz. Verify scores are logged. Test the retake limit: take the same quiz 3 times — 4th attempt should be blocked.
