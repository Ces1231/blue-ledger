Glide config — Member Dues screen
Details screen · All roles
1
Create the screen
Add Screen → Details → source: 👥 Users (current user row). Name it Financials. Add to the nav bar with a wallet/money icon. Visible to all roles — every member needs to see their own status.
2
Add the dues status card (conditional styling)
Add Component → Rich Text or Card. Use Conditional Visibility or an If-Then-Else column to show three different card styles based on the Dues Status column value. Paid = green, Late = amber, Outstanding = red. Each card shows the Amount Owed value and a status badge.
3
Pay Dues button → external URL
Add Component → Button → label: Pay Dues via Zelle → → Action: Open URL → paste your chapter's Zelle link (format: https://enroll.zellepay.com/qr-codes/YOUR_TOKEN or your custom Zelle QR link). Add a second button for PayPal if needed.
4
Submit Expense Report button
Button → label: Submit Expense Report → Action: Open URL → your Google Form URL (built in the Expense Form section below). This opens the form in the member's browser.
5
Hide Pay Dues button when status is Paid
Pay Dues button → Visibility condition: Dues Status is NOT "Paid". No need to show the payment button to members who've already paid. Replace it with a confirmation message when status = Paid.

Glide config — Admin dues panel
Admin Panel · Inline list
1
Add dues summary stats to Admin Panel
Admin Panel screen → top section → add 3 stat displays using Rollup computed columns: Count of members where Dues Status = "Paid", Count = "Late", Count = "Outstanding". Display as a 3-column grid of colored tiles.
2
Add Inline List — all members
Admin Panel → Add Component → Inline List → source: 👥 Users → show all rows (override row owners). Columns: Member initials (avatar), Full Name, Dues Status (badge chip). Sort by Dues Status so Outstanding appears first.
3
Tap → Edit screen
Each list row taps to an Edit screen. Edit fields: Dues Status (Choice: Paid / Late / Outstanding), Dues Paid Date (Date picker), Payment Notes (Text). Submit action: Set Column Values → update the row → trigger Make.com scenario via webhook.
4
Submit action chain
(1) Set Dues Status to selected value. (2) Set Dues Paid Date to entered date. (3) If new status = "Paid": call Make.com webhook to award +50 XP. (4) Show notification: "Dues updated for [member name]". (5) Navigate back to the list.
⚠️ Set the Admin Dues Panel visibility to Role = Admin only. The member's own dues view (Screen 1) is separate and visible to all — they should only ever see their own data, not the full list.

How to create this in Google Forms
~15 min
1
Create the form
Go to forms.google.com → Blank form. Title: The Blue Ledger — Expense Report. Description: Tau Tau Sigma Chapter · Submit within 30 days of expense.
2
Add all 8 fields
Full Name (Short answer, required) → Member Number (Short answer, required) → Date of Expense (Date, required) → Expense Category (Dropdown: Event Supplies / Printing / Travel / Food / Other, required) → Amount (Short answer, required) → Event Name (Short answer, required) → Description (Paragraph, optional) → Receipt (File Upload, required).
3
Link responses to Master Sheet
Form → Responses tab → Link to Spreadsheet → select your Master Sheet → create a new tab called 💸 Expense Reports. All submissions now flow directly into the sheet in real time.
4
Get the shareable form URL
Form → Send button → copy the link. Paste this URL into the Glide "Submit Expense Report" button action. Done — members tap the button, browser opens the form, receipt attaches to Google Drive automatically.
✓
Optional: Confirmation email
Form → Settings → Presentation → Confirmation message: Expense report received. The Treasurer will review within 7 days.. Also enable "Send responders a copy" so members have a paper trail.

Automation
Week 5 Make.com Scenarios
⚡ Scenario 1 — Dues Paid → +50 XP
⬤
Trigger: Google Sheets — Watch Rows → 👥 Users tab → filter: Dues Status = "Paid" AND Dues XP Awarded? ≠ "Yes". Runs every 15 minutes.
→
Action 1: Google Sheets → Add Row → 📋 Engagement Log. Values: Date = today, Member # = from trigger row, Member Name = from trigger row, Activity Type = "Dues Paid (On Time)", XP Awarded = 50, Logged By = "System".
→
Action 2: Google Sheets → Update Row → 👥 Users where Member # matches. Set Total XP = Total XP + 50.
→
Action 3: Google Sheets → Update Row → set Dues XP Awarded? = "Yes". This is the idempotency flag — prevents double-firing.
📧 Scenario 2 — New Expense Report → Notify Treasurer
⬤
Trigger: Google Sheets — Watch Rows → 💸 Expense Reports tab → new row added (Google Forms submission).
→
Action 1: Gmail → Send Email. To: treasurer@yourchapter.org. Subject: New Expense Report: {Member Name} — ${Amount}. Body: all form fields formatted as a clean summary. Include the Google Drive receipt link.
→
Action 2 (optional): Gmail → Send confirmation to the member's email. Body: "Your expense report has been received. Expect reimbursement within 7 days of approval."
✅ Both scenarios together use fewer than 100 Make.com operations per month for an average chapter. Well within the free tier limit of 1,000 operations/month.
