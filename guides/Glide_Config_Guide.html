Glide Build Guide

Every screen in The Blue Ledger, configured step by step. Follow this document in order — Setup → Data → Roles → Screens. Each screen entry includes the Glide layout type, all components, visibility rules, and any formulas or automations required.

⚙️ Step 1 — Glide Project Setup
1
Create a new Glide App (not Pages)
Go to glideapps.com → New App → choose App (not Pages — you need the mobile-first nav bar). Name it The Blue Ledger.
2
Set the primary color
Settings → Theme → Primary color: #001F5B (Navy). Accent color: #C9A84C (Gold). This propagates to buttons and active states.
3
Set the app icon
Settings → App icon → Upload your chapter crest or use a shield emoji placeholder. This appears on the home screen and loading splash.
4
Enable User Profiles
Settings → User Profiles → Enable → map to 👥 Users tab → Email column: Email Address. This is the foundation for row ownership and personalization.
5
Set Sign-In method
Settings → Sign In → Email (allowlist). Paste all member emails from the Users tab into the allowlist. Members sign in with their chapter email — Glide auto-matches to their profile row.
📊 Step 2 — Connect Google Sheets
1
Connect the Master Sheet
Data → Add Source → Google Sheets → select BlueLedger_MasterSheet.xlsx. Glide will import all 6 tabs automatically.
2
Verify table names match exactly
Glide Data Editor should show: 👥 Users, ⚡ Point Economy, 📋 Engagement Log, 🙌 Service Log, 🎖️ Quests & Badges, 📊 PIA Builder.
3
Set column types in Data Editor
For each table, click each column and set the type: Email → Email, Phone → Phone, LinkedIn URL → URL, Total XP → Number, Life Member? → Boolean, Date fields → Date.
4
Add the Avatar Image URL column (computed)
In 👥 Users table → Add Column → If-Then-Else → name it Avatar Image URL. See Computed Columns section at the bottom of this guide for the full formula.
5
Enable Row Owners on Users table
👥 Users → Settings (gear icon) → Row Owners → select Email Address column. This ensures each member only sees their own row. Admins bypass this via role.
🔐 Step 3 — Roles & Visibility Security
1
Create 4 Roles in Glide
Settings → Roles → Add Role × 4: Admin, Chair, PIA, Member. Each maps to the Role column in the Users tab.
2
Map Roles to the Role column
For each Role in Settings → assign condition: Role column = "Admin" (repeat for Chair, PIA, Member). Glide auto-assigns on login based on the signed-in user's row.
3
Protect the Financials screen
On the Financials tab/screen → Visibility → Condition: Role is Admin. This hides the entire tab from Chair, PIA, and Member roles.
4
Protect the Scanner screen
QR Scanner screen → Visibility → Condition: Role is Admin OR Role is Chair. Chairs need scanning access; regular Members never see this.
5
Protect PIA Builder screen
PIA Builder screen → Visibility → Condition: Role is Admin OR Role is PIA.

Scanner Setup (most critical screen)
1
Add Component → Barcode Scanner — this opens the device camera to scan QR codes. Map the scanned value to a temporary field: Scanned Value.
2
Add an Action that triggers after a successful scan: Parse the scanned string to extract the Member # (strip the "MEMBER:" prefix using a Template or Math column).
3
Lookup the member: Add a Lookup computed column that finds the Full Name from the Users table where Member # = Scanned Member #. Display this name as a confirmation to the Chair.
4
Add a Choice component: "Activity Type" — picker from the Point Economy tab. This lets the Chair select what type of check-in (Meeting, Service, etc.).
5
Add a Button: "Confirm Check-In" → Action: Add Row to 📋 Engagement Log with: Member #, Member Name, Activity Type, XP Award (lookup from Point Economy), Date (today), Logged By (current user's Member #).

🧮 Computed Columns Reference
Avatar Image URL (If-Then-Else in Users tab)
IF Total XP ≥ 2500 → "https://[your-storage]/avatar-icon.png" ELSE IF Total XP ≥ 1500 → "https://[your-storage]/avatar-gold.png" ELSE IF Total XP ≥ 1000 → "https://[your-storage]/avatar-silver.png" ELSE IF Total XP ≥ 500 → "https://[your-storage]/avatar-bronze.png" ELSE → "https://[your-storage]/avatar-base.png"
💡Host your PNG files on Google Drive (shared link) or Cloudinary (free tier). Replace [your-storage] with the actual base URL. Name files exactly as shown in the formula.
Avatar Level (If-Then-Else in Users tab)
IF Total XP ≥ 2500 → "Chapter Icon" ELSE IF Total XP ≥ 1500 → "Gold Legend" ELSE IF Total XP ≥ 1000 → "Silver Elite" ELSE IF Total XP ≥ 500 → "Bronze Varsity" ELSE → "Neophyte"
Profile Complete? (If-Then-Else in Users tab)
IF Full Name is not empty AND Email Address is not empty AND Employer is not empty AND Job Title is not empty AND City / State is not empty → "Yes" ELSE → "No"
QR Data (Template column in Users tab)
MEMBER:{Member #} → Example output: MEMBER:ΤΣΣ-001
