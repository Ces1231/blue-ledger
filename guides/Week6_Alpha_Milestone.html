Preparation
Pre-Event Setup Checklist
Complete all of these before the event — not on the day of.
48 hours before
Do this now
All E-Board members added to Glide allowlist
Go to Glide Settings → Sign In → paste all E-Board emails. They must sign in before the event — not in the parking lot.
Assign roles in Users tab
Open Master Sheet → 👥 Users tab → fill Role column for all E-Board members: Admin for President, Chair for any Committee Chairs attending.
Pre-populate all E-Board profiles
Add their Name, Member #, Induction Year, and Email to the Users tab so QR codes generate automatically on first sign-in.
Test scan from your own phone
Open Digital ID on one phone. Open Scanner on a second phone. Scan — member name should appear. Confirm Check-In — verify Engagement Log row in the sheet.
Brief the Chair running the scanner
15-minute walkthrough: open Scanner tab, select activity, scan, confirm, repeat. Practice until it feels fast.
At the Event
Live Event Runbook
During the event — scanner flow
~2 hours
1
Chair opens scanner, sets activity type
Select 'Chapter Meeting (on time)' from the dropdown before anyone walks in. Don't change activity mid-scan — finish all check-ins for one type before switching.
2
Each brother opens Digital ID on their phone
They tap their ID card tab and show the QR code. Make sure they're signed in before arriving — first-time sign-in takes 2 minutes.
3
Chair scans, confirms, moves immediately to next
The confirmation screen shows for ~2 seconds. Tap 'Scan Next' — ready for the next person. Target: under 10 seconds per person.
4
Monitor sheet in real time on a laptop
Open 📋 Engagement Log in Google Sheets on a second device. Watch rows appear as each brother gets scanned. This is your sanity check.
5
After the meeting — check the leaderboard
Pull up the Leaderboard screen. It should now reflect updated XP for everyone scanned. Screenshot it and post in the chapter group chat — first viral moment.

Post-Alpha
Feedback & Fixes
What to ask E-Board after the event
10-min debrief
?
Was sign-in confusing?
If yes: add clearer instructions to the splash screen. Consider a 'First time? Tap here' help text below the sign-in button.
?
Did the scanner feel fast enough?
If slow: check your Make.com automation timing. The scan itself is instant — any lag is the sheet sync. Acceptable is under 60 seconds for XP to appear.
?
Was anything missing on the Home Dashboard?
Common feedback: brothers want to see their rank number prominently. Add a 'Chapter Rank: #X' stat card to the home hero section.
?
Did anyone have trouble with the QR code?
Lighting matters. Dim venues make QR scanning harder. Solution: maximum brightness on the member's phone. Note this for the full launch briefing.
?
Any data show up wrong?
Check for duplicate rows in Engagement Log (Make.com fired twice), wrong XP values (Point Economy lookup issue), or missing member names (QR Data template column not set up correctly).
